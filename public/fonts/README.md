# Local interface fonts

Source Sans 3 (400–700) is used for reading and controls. Newsreader (400–600, optical sizing) is used for editorial headings. The Latin WOFF2 subsets are served locally; other characters use the declared system fallbacks. No Google Fonts request is made by the app.

Downloaded from the Google Fonts distribution on 2026-09-09:

- Source Sans 3: https://fonts.gstatic.com/s/sourcesans3/v19/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2
- Newsreader: https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjA.woff2

Both use the SIL Open Font License. The unmodified licence files in this directory were obtained from the corresponding `google/fonts` repository directories (`ofl/sourcesans3` and `ofl/newsreader`).
